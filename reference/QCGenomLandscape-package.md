# QCGenomLandscape: Portrait of Genomic Data Availability for Quebec Species

Tools to query BOLD Systems and NCBI for genomic sequence availability
across the species of the Biodiversite Quebec (BDQC) species list,
cross-reference conservation status (COSEPAC/LEMV), and build summary
tables and figures.
